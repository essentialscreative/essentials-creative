Every change above updates the composition live. The composition obeys the matrix (month palette + register mode), the kappazuri grammar (max 2 inks + 1 spark, one mon, cropped figure, type at fidelity, mis-register where the edges meet), and the kamon discipline (the motif fits a circle, carved negative space, single ink).

Export · Print to PDF opens the system print dialog — choose "Save as PDF" for a press-ready output. Download · SVG saves the composition as editable vector. Random picks a cell for play.
